# Table redesign

A new look for the game table: a round wooden table seen from above, name panels round it,
opponents' cards standing in racks on the rim, and panels pinned to the window corners.

- **Start here:** [`IMPLEMENTATION_PLAN.md`](IMPLEMENTATION_PLAN.md), the step-by-step plan for
  building it in the Qt client.
- **The target:** [`mockup/romanian_whist_table.html`](mockup/romanian_whist_table.html). Download it
  and open it in a browser; it is playable and works offline.
- **Screenshots** of the mock-up at 1920×1080: [`screenshots/`](screenshots/).

Status: designed and approved as a mock-up; not yet implemented in the client.
